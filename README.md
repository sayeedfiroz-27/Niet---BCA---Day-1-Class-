# Python Day 1 & 2 - Programming Basics and Python Fundamentals

Simple Hinglish GitHub Pages notes for Python beginners. The main page now follows the reference-style format with a title page, table of contents, module header, topic-wise theory, real-world use cases, practical code, output, and detailed line-by-line code explanation. It covers programming basics, Python introduction, interpreter basics, first Python program, variables, naming rules, data types, type casting, input/output, comments, syntax, and practical coding examples for a 5-hour learning session.

## Files

- `index.html` - Complete GitHub Pages notes document with title page, TOC, theory, 2-3 examples per major topic, practical code, sample output, detailed code explanation, recap, and student tasks.
- `direct-reading-notes.html` - Direct paragraph-by-paragraph class reading notes in natural Hinglish.
- `learners-notes.html` - Simple English learner notes in paragraph format with code examples and practice tasks.
- `examples/day1_practice.py` - Runnable Python practice file used in the lesson.
- `examples/day1_student_profile.py` - Extra interesting practical for the 5-hour session.

## How to Use

Open `index.html` for the full structured GitHub Pages document. Learners should type the code examples themselves and run them in Python, VS Code, or Jupyter Notebook.

```bash
python examples/day1_practice.py
python examples/day1_student_profile.py
```
